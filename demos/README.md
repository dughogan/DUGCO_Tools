# Demo videos

Short clips that show a node or workflow in use. One folder per tool or workflow:

```
demos/
  <tool_or_workflow_name>/
    demo.mp4
    thumbnail.jpg
```

## File size

GitHub rejects any file over 100 MB and the whole repository is downloaded by everyone who installs the pack, so keep what lives here small:

- Short previews (H.264 MP4, ideally under 25 MB) go in this folder.
- Long or full-resolution videos go on YouTube or as an attachment on a GitHub Release, linked from the main [README](../README.md).
