# Workflows

Each workflow is a ComfyUI `.json` file in this folder. ComfyUI reads this folder, so once the pack is installed the workflows also show up in the Templates browser under **DUGCO Tools**.

## Adding a workflow

1. Save the workflow from ComfyUI as `<short_name>.json` in this folder.
2. Add a thumbnail with the same name next to it (`<short_name>.jpg` or `.webp`) so it has a preview in the Templates browser.
3. Add a row to the Workflows table in the main [README](../README.md).

Keep the workflow self-explanatory: name the groups, leave a note node listing the models it needs and where they go.
